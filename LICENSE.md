# License

> **Status:** a definir antes del primer deploy público.

Hay dos decisiones pendientes que toma el dueño del proyecto, no la implementación:

## 1. Código del sitio (este repo)

Privado o público.

- **Privado** (default razonable para el código de un producto comercial): mantener el repo de GitHub privado y no se necesita un archivo `LICENSE`. El código queda como propiedad de la organización.
- **Público / open source**: elegir entre MIT, Apache 2.0, AGPL u otra. Decisión editorial-comercial — abrir el código de un diario tiene implicancias (terceros pueden copiarlo, embedarlo, fork-earlo) que conviene mirar con cabeza fría.

## 2. Contenido editorial (notas, fotos, ilustraciones)

Independiente de la decisión sobre el código.

- **All rights reserved** (default): nadie puede republicar sin autorización expresa.
- **Creative Commons BY-NC**: se permite compartir con atribución para uso no comercial.
- **Creative Commons BY-SA**: se permite compartir con atribución manteniendo la misma licencia.

Esta decisión la toma la dirección editorial, no el equipo técnico.

Hasta que ambas decisiones estén tomadas, código y contenido se asumen **all rights reserved** y este archivo queda como recordatorio de que la decisión está pendiente.
